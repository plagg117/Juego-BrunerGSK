# El Seminario de Bruner

Juego educativo para la clase de Psicología, basado en el capítulo
"El estudio apropiado del hombre" de *Actos de significado* (J. Bruner).

## Estructura

- `src/models/`: datos y reglas del juego
- `src/views/`: lo que se muestra en pantalla
- `src/controllers/`: conectan modelos y vistas
- `src/data/`: contenido (salas, preguntas, cassettes) en JSON
- `assets/`: audio, imágenes y estilos
- `docs/`: documentación del proyecto
